# 使用教程

## 创建与加入教室

打开网站，右上角选择中文或 English。填写昵称、教室名称，选择公开或私密后创建教室。

公开教室在大厅可见。私密教室通过「复制邀请链接」邀请朋友，朋友打开后输入昵称即可加入。昵称为临时访客身份，没有密码账号。

## 选座与观看

点击空座预览视野，再点击入座按钮确认。已占用座位会显示人物，同时抢同一座位以服务器确认结果为准。

拖动画面或按方向键转头，点击「看向幕布」回正。返回座位图可换座。调暗灯光和雨声按钮用于调整个人环境。

房主点击「视频链接」粘贴完整链接，也支持从分享文案或受支持的 iframe 中提取视频。

| 来源 | 范围 | 同步情况 |
|---|---|---|
| YouTube | 普通、短链、shorts/live/embed | IFrame API，同伴需能访问 YouTube |
| B 站 | BV、AV、分 P、b23.tv、官方 iframe | 同一视频，各自操作播放器 |
| 抖音 | 视频页、modal_id、短分享和官方播放器 | 同一视频，各自操作播放器 |
| 腾讯视频、优酷 | 可识别 ID 的单集页、官方 iframe | 同一视频，各自操作播放器 |
| 小红书 | 尝试解析公开页和短分享 | 部分服务器仍失败，登录验证和签名会影响结果 |
| 文件直链 | HTTPS MP4/WebM/M4V/OGV | 编码兼容且允许 CORS 时同步 |
| 上传视频 | MP4/WebM，最大 200 MB | 上传到服务器后同房间共享同步 |
| 内置示例 | 无需外部平台 | 同步播放 |

房主控制支持同步视频的播放、暂停和进度，各观众独立调音量。自动播放受限时点「启用播放」。无法解锁平台付费、地域或登录限制。

上传默认总容量 1 GB，可配置 MAX_UPLOAD_GB。文件保存七天，每小时检查清理。上传链接为随机地址，持有地址的人可以访问。

## 聊天与离开

右侧发消息，全房间可见，座位旁会短暂显示消息气泡，房间保留最近 80 条消息。

房主离开后，控制权转给最早留下的成员。约两分钟没有心跳会释放座位，最后一人离开会关闭房间。后台网页被浏览器暂停时可能需要重新加入。

## 常见问题

- 先试内置示例判断本地播放是否正常。
- MP4 黑屏时检查浏览器是否支持编码，以及文件源是否允许跨域。
- 平台链接失败时保留完整分享参数，尤其是小红书，记录 XHS 错误码供部署者查看日志。
- 邀请失效时确认教室还有成员并重新创建邀请。
- 手机访问失败时检查解析、HTTPS、云防火墙，再通过不同网络实测。
